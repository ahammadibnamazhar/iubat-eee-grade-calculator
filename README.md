## What It Does

IUBAT EEE Academic Calculator brings essential academic
calculation tools into one place.

- GPA & CGPA calculation
- Marks-to-grade conversion
- Target GPA calculation
- Semester planning
- IUBAT EEE course data
- Local data storage
- Export and print
